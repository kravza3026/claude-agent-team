# Внесок

## Структура

```
agents/ skills/ dashboard/    ← вміст, що встановлюється
installer/install.js          ← єдина реалізація установника (Node ≥ 18, без залежностей)
install.* uninstall.*         ← тонкі обгортки (перевіряють Node і викликають install.js)
tools/gen-docs.js             ← генерація таблиць у docs із frontmatter
tests/smoke.js                ← smoke-тести (node tests/smoke.js)
docs/                         ← документація (українською)
```

## Перед pull request

```sh
node tools/gen-docs.js     # оновити таблиці агентів/навичок у docs
node tests/smoke.js        # повний smoke-тест
```
`smoke.js` перевіряє: синтаксис усіх `.js`, frontmatter агентів і навичок (`name`, `description`, `name` = ім'я теки/файла, посилання `skills:` існують), установку/ідемпотентність/видалення в тимчасовій теці, безпечне поводження зі `settings.json`, актуальність `docs`, відсутність персональних даних, токенів і ключів.

## Двомовність (UA/EN)

- Основна мова — українська: `README.md`, `docs/*.md`. Англійські відповідники: `README.en.md`, `docs/en/*.md` — повний переклад із тими самими розділами (кількість заголовків `##` має збігатися) і незмінними блоками коду. На початку кожного файла — рядок перемикача `🇺🇦 Українська | 🇬🇧 English`.
- Англійські описи агентів і навичок (для англомовних таблиць) лежать у `docs/i18n/descriptions.en.json` (`agents.<name>`, `skills.<name>`); frontmatter агентів/навичок лишається українським, щоб не додавати нестандартних ключів. Новий агент/навичка без англійського опису не пройде `node tools/gen-docs.js --check`.
- Таблиці генерує `node tools/gen-docs.js` для обох мов. `tests/smoke.js` перевіряє паритет файлів, перемикачі, кількість `##`, відсутність кирилиці в англійських файлах (дозволені лише рядок перемикача) і відсутність битих відносних посилань.
- Повідомлення установника українською записані в коді; англійські — у таблиці `EN` у `installer/install.js` (`--lang en`). Нове повідомлення = новий запис у таблиці (тест перевіряє, що англійський вивід без кирилиці).

## Правила

- Мова документації й текстів агентів — українська; технічні терміни та ідентифікатори — оригінальні.
- Кросплатформність: `path.join`, `os.homedir()`, без bash-ізмів у `.js`; `.sh`-скрипти — POSIX sh; для Windows окремі `.ps1`/`.cmd`.
- Жодних персональних даних, назв чужих проєктів/клієнтів, шляхів вашої машини, токенів. Використовуйте нейтральні приклади.
- Установник не має змінювати чужі ключі `settings.json` і не повинен видаляти файли, змінені користувачем.
- Нові залежності не додаємо (Node stdlib).
- Команди Claude Code в `docs/CLAUDE_SETUP.md` позначайте **[звірено]** лише після перевірки `claude --help` актуальної версії, інакше **[перевірте]**; не вигадуйте URL і прапорців (див. [CLAUDE_SETUP.md](CLAUDE_SETUP.md)).
- Новий агент/навичка: див. `docs/AGENTS.md` і `docs/SKILLS.md`.
- Windows/macOS-гілки перевіряйте принаймні юніт-тестами побудови рядків (`tests/smoke.js`, розділ platform) і, якщо можете, на реальній ОС; повідомляйте, що саме запускали.
