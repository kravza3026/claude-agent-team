# Айдентика з даних компанії

Вхід: `COMPANY.local.md` (назва, адреса, діяльність). Результат: `docs/brand.md` у проєкті.

## Кроки
1. Визнач сферу й аудиторію (B2B/B2C, довіра/креатив/технології).
2. Підбери настрій за сферою:
   - кібербезпека, IT, консалтинг: темно-синій/графіт + один холодний акцент (cyan/teal), чіткі форми;
   - фінанси, право: глибокий синій/зелений, нейтральні світлі тла, строгість;
   - медицина, догляд: світлі, спокійні кольори, багато повітря;
   - будівництво, виробництво: теплі нейтральні + контрастний акцент;
   - креатив, студії: сміливіша палітра, нестандартна сітка.
3. Палітра: primary, accent, фони (світлий/темний), текст, success/error. Контраст тексту ≥ 4.5:1 (перевір).
4. Типографіка: 1 шрифт для заголовків + 1 для тексту (Google Fonts), шкала розмірів, line-height.
5. Тон текстів: коротко, конкретно, без кліше та вигаданих цифр/нагород/клієнтів.
6. Запиши токени як CSS-змінні (`:root { --color-primary: ... }`) і використовуй лише їх.

## Правила
- Палітра має відрізнятися від сусідніх гілок-сайтів: подивись їхні токени, не повторюй.
- Не вигадуй факти про компанію: сертифікації, роки, кількість клієнтів.
