# Craft візуальних асетів

Сайт виглядає дорого, коли всі зображення, іконки й фони належать одній системі. Вибери й дотримуйся: стиль іконок, радіус, товщину лінії, палітру, обробку фото.

## Іконки
- Один набір на сайт: лінійні (stroke 1.5–2px, `stroke-linecap:round`) або заливні. Генеруй власний SVG-sprite (`<symbol>`) або Lucide/Phosphor/Tabler (MIT, інлайн SVG без runtime). Розмір кратний 4/8, `currentColor`, `aria-hidden` якщо декоративні.
- Жодних emoji як іконок в інтерфейсі; жодного змішування наборів.

## SVG-ілюстрації та патерни
- Паттерни: сітка/крапки/діагональні лінії/хвилі/топографія/hex через `<pattern>` або `background-image: url("data:image/svg+xml,…")` з encodeURIComponent; opacity 0.04–0.12, `mask-image` градієнтом, щоб не конкурував із текстом.
- Прості геометричні ілюстрації з 3–4 форм у брендових кольорах; лінійні схеми (як працює, схема підключення) — SVG з `stroke-dasharray` анімацією.
- Оптимізуй: svgo-подібне очищення, `viewBox` без width/height, шляхи без зайвих груп. Лого — контури, не текст.
- НЕ використовуй SVG-малюнки замість реальних фото товарів, якщо завдання вимагає реальні фото.

## Фони й текстури
- **Mesh-градієнт**: 3–5 radial-gradient у oklch + `filter: blur(40px)`/`background-blend-mode`; повільна анімація `@property` кутів.
- **Grain/noise**: інлайн SVG `<feTurbulence baseFrequency=".8" numOctaves="2">` як `background` з `mix-blend-mode: overlay; opacity:.06–.15`, `pointer-events:none`; не на кожен блок, а на кілька великих поверхонь.
- Лінії-контури (topo), halftone, scanlines — як акцент у банерах (також у шейдерах).
- Скло: `backdrop-filter: blur(14px) saturate(1.4)` + тонка 1px рамка `rgb(255 255 255 / .18)`; лише на кількох елементах; fallback суцільний напівпрозорий фон.
- Тіні шарами: `0 1px 2px rgb(0 0 0/.06), 0 8px 24px -8px rgb(0 0 0/.18)`; кольорові тіні від кольору бренду замість чорних.

## Фото
- Каталог: ВСІ фото однакового співвідношення (напр. 800×600 або 4:5), однаковий кадр (товар по центру, схожий фон), єдина обробка (легка корекція експозиції, однаковий tone). Перевіряй візуально відповідність товару, відсутність сторонніх брендів/написів іншою мовою/ватермарок.
- Обробка: **duotone** (CSS `mix-blend-mode`/SVG feColorMatrix) для атмосферних фото; `object-fit: cover` + `object-position`; маски `clip-path`/арки/кола для композицій.
- Формати: AVIF → WebP → JPEG через `<picture>`; `srcset`/`sizes`; `loading="lazy"` + `decoding="async"`, `fetchpriority="high"` для hero; фіксовані `width/height` (без CLS); ImageMagick: `convert in.jpg -resize 800x600^ -gravity center -extent 800x600 -quality 82 -strip out.jpg`; `cwebp`/`avifenc` якщо є.
- Джерела вільних фото: Wikimedia Commons, WordPress Photo Directory, StockSnap (Unsplash/Pexels/Pixabay блокують автодоступ). Атрибуція в `docs/image-credits.md` (автор, ліцензія, URL).
- Не вигадуй і не генеруй «реальні» фото товарів: використовуй справжні.

## Лого й favicon
- SVG-знак + вордмарк (контури); варіанти: основний, світлий (для темного фону), моно, знак для favicon. Favicon: SVG + ICO (16/32/48) + apple-touch 180 + 192/512 PNG + manifest; контраст на світлому й темному tab (однотонний знак або знак у плитці).
- Знак має читатись у 16×16; не використовуй дрібні деталі.

## Банери й графіка
- Композиція: один фокус, 60/30/10 колір, великий контраст тексту (≥4.5:1 поверх зображення з градієнтною підкладкою), чіткий CTA.
- Стилі: фото + геометрична форма, великі цифри/outline-текст, діагональні розрізи, стікери-«штампи» (обертання -6°…6°), стрічки marquee, градієнтна рамка (`conic-gradient` border).

## Перевірка
- Усі зображення завантажуються (жодних 404), `alt` змістовні (декор — `alt=""`), вага hero ≤ 250KB, каталожне фото ≤ 120KB.
- Перевір у темній і світлій темі, на 320px; зображення не розтягують контейнер (`max-width:100%`, `min-width:0`).
- Узгодженість: випадково обране фото/іконка не вибивається стилем; перегляд contact sheet усіх фото каталогу.
