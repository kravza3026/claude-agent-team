# Унікальність верстки

Мета: власник відкриває дві гілки поруч і НЕ бачить, що це один шаблон. Зміна кольору й шрифту — НЕ різниця.

## 1. Розвідка (обов'язково перед проєктуванням)
- Прочитай `docs/brand.md`, `resources/views/*`, `public/assets/mockup/css/app.css` ПОТОЧНОГО дерева — це дизайн-попередник. Випиши: палітра, шрифти, сітка hero, порядок секцій, форма карток, форма кнопок, радіуси, іконки, WebGL-сцена.
- `git branch` / `git log --stat -3` (лише читання) — дізнайся, які ще дизайни існують.
- Створи `docs/variety-matrix.md`: таблиця «було → стало» по осях нижче. Мінімум 6 з 8 осей мають змінитись.

## 2. Осі відмінності (змінюй структурно, не косметично)
1. **Архетип компонування hero**: split 50/50 · full-bleed canvas з текстом поверх · центрований великий заголовок · асиметрична сітка з вертикальним текстом · «магазин-вітрина» (hero = каталог-стрічка) · editorial (великі цифри/числа).
2. **Навігація**: верхня смуга · бічна вертикальна · «плаваюча таблетка» · mega-menu · нижня панель на мобільному.
3. **Сітка**: 12-col класична · bento-grid (різні розміри плиток) · masonry · горизонтальні скрол-секції · шахова асиметрія · модульна «журнальна».
4. **Форма карток товару**: вертикальна · горизонтальна · overlay-текст на фото · «лістинг-рядок» з таблицею специфікацій · картка з hover-розкриттям.
5. **Геометрія**: гострі кути / великі радіуси / пілюлі / зрізані (clip-path) кути / лінійні рамки (1px) / тіні-«брутал».
6. **Типографіка**: serif display · grotesk · mono-акценти · variable font з анімацією ваги · великий outline-текст · масштабна шкала (x1.25 vs x1.618).
7. **Колір і фон**: темна/світла/двоколірна тема, градієнтні меші, зерно, паттерни; НЕ повторюй пару hue попередників (відстань по колу ≥ 60°).
8. **Ритм сторінки**: порядок і кількість секцій, розділювачі (діагональ, хвиля, лінія, маркі), щільність/повітря.

## 3. Правила
- Не копіюй CSS-класи, назви секцій, тексти, заголовки FAQ, структури HTML попередника. Перейменуй, перепиши, переорганізуй.
- Лого — інша ідея (не те саме сонце/коло): моно-знак, літерний знак, абстрактна форма; інший вордмарк.
- Різні WebGL-сцени (див. скіл motion-banners), не «та сама сцена з іншими кольорами».
- Неповторні мікро-деталі: курсор, loader, 404, порожній кошик, toast — кожен у стилі бренду.
- Кожна сторінка має власну композицію, але спільну дизайн-систему.

## 4. Самоперевірка перед здачею
- Заповни `docs/variety-matrix.md`; якщо < 6 осей змінено — переробити.
- Зроби скрін головної й порівняй зі скрінами попередника (silhouette test: зменш до 10% — композиції мають виглядати різними).
- У звіті напиши «чим відрізняється від <гілка>» по осях.
