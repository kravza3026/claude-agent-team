# Каталог композицій

Для кожного сайту обери ОДИН архетип у кожній групі й запиши вибір у `docs/variety-matrix.md`. Не повторюй вибір сусідніх сайтів. Усі композиції мобільні-перші, без horizontal overflow (grid-діти `min-width:0`).

## 1. Hero
- **Editorial**: великий serif-заголовок + 2–3 числа (count-up) + арка/маска-вікно зі сценою. Преміум, сервіси.
- **Full-bleed canvas**: WebGL/відео на весь екран, текст зліва внизу, прогрес-скрол. Бренд-сайти.
- **Split asymmetric 7/5**: текст + «зламана» сітка карток/фото, що виходять за рамки. Retail.
- **Centered mega-type**: гігантський заголовок на 2 рядки, під ним стрічка продуктів/логотипів, що рухається. 
- **Product shelf**: hero = горизонтальна полиця товарів із hover-розкриттям. Магазини.
- **Scroll-story**: sticky-сцена, що змінюється при скролі (3–4 кроки). Технологічні продукти.
- **Search/configurator-first**: hero = форма-підбір (калькулятор, фільтр) — користь одразу.

## 2. Навігація
- Верхня смуга з mega-menu (мініатюри категорій) · **floating pill** (центр згори/знизу, ховається при скролі) · вертикальний rail · бічна висувна панель · bottom-tab-bar на мобільному · «сходинка» з двох рядків (utility + main). Мобільне: dialog з focus-trap, Esc, цілі ≥44px.

## 3. Сітки секцій
- **Bento** (3–4 плитки різного розміру, `grid-template-areas`) — переваги/акції.
- **Staggered grid** (кожна 2-га картка зсунута на 2rem) — каталоги.
- **Masonry** (`columns` або grid + `grid-row: span`) — галереї/блог.
- **Horizontal rail** (`scroll-snap`, перші елементи біля краю, стрілки, drag) — добірки.
- **Sticky stack** (картки накладаються при скролі, `position: sticky; top: calc(var(--i) * 1rem)`) — сервіси/кроки.
- **Index list** (нумерований список з великими рядками + preview-зображення при hover) — категорії.
- **Chess rows** (фото/текст чергуються) — сервіси, історії.
- **Timeline/steps** (вертикальна лінія з вузлами, що заповнюється при скролі) — «як це працює».
- **Tabs/accordion with preview** (ліворуч список, праворуч великий preview) — продукти/пакети.
- **Marquee strips** (подвійні, у різні боки, різні швидкості) — бренди, переваги.

## 4. Картки товарів
- Вертикальна класична · **listing row** (фото | назва+специфікації | ціна+кнопка) · **overlay** (текст на фото, градієнт знизу) · **flip** (зворот зі специфікаціями; перемикання кнопкою, не лише hover) · «quick view» з розкриттям під карткою · mini-card у rail · compare-row. Завжди: aspect-ratio однаковий, ціна tabular-nums, кнопка ≥44px.

## 5. Секції довіри/конверсії
- Лічильники (count-up) · відгуки-масонрі · логотипи партнерів-marquee (тільки реальні!) · FAQ accordion `<details>` з анімацією · гарантії-стрічка · «підбери систему» (stepper) · sticky CTA-панель на мобільному · діагональний CTA з шейдерним фоном.

## 6. Футер
- Mega-footer (4 колонки + велике контактне число) · «гігантський вордмарк» на всю ширину · мінімальний рядок + адреса · футер із картою. Адреса, телефон, privacy; без соцмереж, якщо це вимога.

## 7. Ритм сторінки
- Чергуй щільні й порожні секції; різна висота (не всі «80vh»); розділювачі: діагональ (`clip-path`), хвиля SVG, шейдерна смуга, текстова marquee, лінія з міткою. Максимум 2 секції підряд з однаковою сіткою.
- Контраст фонів: світла → темна → акцентна → світла (але не «зебра» кожного разу).

## 8. Скелети (використовуй і адаптуй, не копіюй дослівно)
```css
/* bento */
.bento{display:grid;gap:1rem;grid-template-columns:repeat(6,minmax(0,1fr));grid-auto-rows:minmax(9rem,auto)}
.bento>*{min-width:0}.b1{grid-column:span 4;grid-row:span 2}.b2{grid-column:span 2}.b3{grid-column:span 2}
@media(max-width:720px){.bento{grid-template-columns:minmax(0,1fr)}.bento>*{grid-column:auto!important;grid-row:auto!important}}
/* sticky stack */
.stack>article{position:sticky;top:calc(5rem + var(--i)*1rem)}
/* rail */
.rail{display:grid;grid-auto-flow:column;grid-auto-columns:min(80%,22rem);gap:1rem;overflow-x:auto;scroll-snap-type:x mandatory;overscroll-behavior-x:contain}
.rail>*{scroll-snap-align:start}
```

## 9. Правила якості
- Ієрархія: одна головна дія на екран; відступи кратні 8; сітка має логіку (колонки/ряди узгоджені між секціями).
- Не більше 3–4 різних акцентних форм на сторінку (радіуси/кути узгоджені з geometry-обраною на сайт).
- Кожна сторінка — власна композиція, спільна дизайн-система (кольори, шрифти, кнопки, форми).
- Адаптив: перебудовуй композицію, а не лише зменшуй (hero-split → стовпчик, bento → стопка, rail лишається горизонтальним, sticky stack → звичайний список на коротких екранах).
- Нічого фіксованого, що перекриває контент або кнопки «в кошик».
